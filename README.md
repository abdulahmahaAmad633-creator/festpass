# FestPass – Event Management Website

FestPass lets students explore upcoming campus events, save favourites, and register to get a digital pass.

## Features
- Hero with a live countdown to the next event and a moving event ticker
- Ticket-style event list: date, name, venue, time, short description and seats left
- Search, category filters, sorting (date, seats, name) and "saved only" view
- Slide-in details panel with a shareable link for each event
- Registration form with JavaScript validation (name, email, 10-digit phone, event) and a ticket confirmation
- Seat counter that goes down with every registration and blocks sold-out events
- Duplicate registration check, saved favourites and "My passes" list (Local Storage)
- Dark / light mode, responsive on mobile, tablet and desktop, keyboard focus styles

## Tech
HTML5, CSS3 (Grid, Flexbox, CSS variables, animations), vanilla JavaScript, Git & GitHub
